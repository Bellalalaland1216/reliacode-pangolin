# 线上穿山甲生产码包：一键生成并下载

此目录保存 2026-09-16 已部署到 `8.140.52.117` 的 `traceability-system` 页面源码。本次同步范围仅为 [`views/downloads.ejs`](traceability-system/views/downloads.ejs)。它是当前生产试点的 Express/EJS 页面，和仓库主线的 `apps/scan-api`、`apps/scan-web` 属于不同实现；不能把此文件直接覆盖到主线应用，也不能仅凭此文件重新部署完整生产服务。

页面在管理员确认生码后，用服务端返回的当前码包 ID 下载链接 TXT，并检查响应中的码数量。浏览器保存失败时保留同一码包的重新下载链接；生成成功后按钮保持禁用，避免用户为下载失败再次点击生码。码包记录里原有的链接 TXT、纯码 TXT 和图片 ZIP 下载不变。

上线前 EJS 和脚本语法通过，隔离前端检查覆盖下载成功与失败；线上独立管理员登录、页面可访问、PM2/公网 `/readyz` 就绪。当前后端接入临时隔离数据库，实测生成并导出 50,000 个唯一单品码，检查 TXT 的 UTF-8、Windows CRLF、数量和任务绑定；未向生产业务数据库写入测试码。

当前网页版生码接口还没有持久幂等键，网络超时后再次提交仍可能重复生码。工厂印刷软件的真实导入与试印也尚待验收。这份源码同步只记录已上线的一键下载页面行为，不代表工厂交付全流程已完成。
